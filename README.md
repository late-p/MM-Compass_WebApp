# MM-Compass 회의용 모바일 웹앱 (PWA)

회의용 인력 가동 현황을 **모바일에서 한눈에** 보는 설치형 웹앱입니다. 로그인·서버·DB 없이 정적 파일만으로 동작합니다.

## 🔗 체험해 보기 (가상 샘플 데이터)
**https://late-p.github.io/MM-Compass_WebApp/**

- 폰이나 PC 브라우저에서 링크를 열면 바로 실행됩니다. 로그인이 필요 없습니다.
- 화면 속 법인·조직·사람 이름과 숫자는 **모두 가상**입니다(실제 회사 데이터가 아닙니다).
- 설치: Android(Chrome) = 하단 "설치" 안내 · iPhone = Safari → 공유 ⎋ → 홈 화면에 추가
- PC에서는 개발자도구(F12) → 휴대폰 아이콘, 또는 아래 "내 PC에서 실행"의 폰 틀 미리보기를 쓰면 모바일 화면으로 볼 수 있습니다.

## 내 PC에서 실행 (Python 3.9+, 추가 설치 없음)
```
py preview.py --demo      # 가상 데이터로 빌드 후 브라우저에 폰 틀로 열림 (http://localhost:8811/phone)
```
`미리보기.bat`은 실데이터용입니다(포털이 있는 PC에서만 동작).

## ⚠️ 실데이터 모드 (이 저장소에는 데이터가 없습니다)
이 웹앱은 원래 사내 포털(MM-Compass)이 게시한 회의용 화면에서 수치를 읽어 만듭니다(`build.py`, `sync.py`).
**실데이터(조직별 수치, 대기 인원 이름 등)는 공개 저장소에 올리지 않습니다** — `.gitignore`가 `dist/`, `.token`을 제외합니다.
실데이터 빌드를 공개 주소(GitHub Pages 등)에 올리면 누구나 볼 수 있으니 사내 서버/VPN 또는 인증이 있는 곳에만 올리세요.

(아래는 실데이터 모드 상세 설명입니다)

포털(MM-Compass)의 회의용 화면에서 **모바일에서 한눈에 볼 핵심만** 뽑아 보여주는 설치형 웹앱입니다.
링크를 문자로 보내 → 눌러서 바로 보고 → 홈 화면에 설치. **로그인·서버·DB 없음.**
자세한 표·명단은 PC 포털에서, 모바일은 요약만.

## 화면 (하단 탭 5개)
| 탭 | 내용 |
|---|---|
| 요약 | 전사 가득률·가동률(대비 증감, 목표선), 대기·투입·비매출 제외 가득률, 법인별, 눈에 띄는 변화 |
| 조직 | 본부 카드 → 사업부 → 팀 펼침, 정렬(기본/가득률 낮은순/대기 많은순), 월별 미니 추이 |
| 추이 | 월별 가득률·가동률 그래프(터치/드래그로 월 선택), 전사·본부 전환, 연간 추정 가득률·가동률(나침반 2개) |
| 대기 | 전사 대기 MM·증감·대기율, 법인별 비중, 대기 많은 사업부 TOP 3 (전체 보기) — 사업부를 누르면 **팀과 대기 인원 이름·MM** |
| 인사 | 이번 주 인사 변동 건수·내역(유형·조직·영향 MM), 휴직 인원 수 |

- **실명이 들어가는 곳은 '대기' 탭의 사업부 상세 한 군데뿐입니다**(대기 중인 인원의 이름과 대기 MM). 인사 변동·휴직은 조직·건수만 있고 이름·직급·직무는 어디에도 없습니다.
- 팀 합계는 포털 엔진의 조직 단위 계산값이고 사람 값은 개인별 값이라, 일부 팀(투입이 가동대상을 넘는 팀 등)은 합이 다를 수 있어 `*`로 표시합니다. 포털의 대기 인력 표와 같은 값입니다.
- 숫자는 포털 회의용 화면에 표시된 값을 그대로 읽어 오므로 포털과 같습니다(별도 계산 없음). 증감 색은 포털과 같게 **증가=빨강▲, 감소=초록▼**.

## 데이터 구조 (매주 바뀌는 것과 안 바뀌는 것을 분리)
```
포털 게시 ─▶ extract.py(수치만 추출) ─▶ dist/m-<비밀주소>/
                                         ├ index.html          앱 껍데기 (거의 안 바뀜, 53KB)
                                         ├ sw.js, manifest…    설치·오프라인
                                         └ data/
                                            ├ latest.json      가장 최근 게시 주차   ← 매주 이것만 바뀜 (~22KB)
                                            ├ weeks.json       주차 목록 (지난 주차 선택용)
                                            └ <주차>.json      주차별 (최근 8개)
```
- 데이터 계약: `{schema, rev, generated, week:{label,title,asof,meet}, d:{…}}`
  - `rev` = 내용 해시 → 앱이 "새 데이터가 왔는지" 판단 / `schema` = 앱이 모르는 새 형식이면 "앱 업데이트 필요"로 안내
- 포털 화면 형식이 바뀌어 값을 못 찾으면 **조용히 틀린 숫자를 내지 않고 빌드가 멈추고** 어디가 바뀌었는지 알려 줍니다.
  (10월 2·3주차처럼 예전 형식 주차는 자동으로 건너뜁니다.)

## 최신 정보로 갱신되는 방식
**폰 쪽 (앱이 알아서)**
- 앱을 열면 저장된 데이터를 **즉시** 보여주고, 뒤에서 최신을 확인해 바뀌었으면 갱신 + "새 데이터로 갱신했어요" 알림
- 앱으로 돌아올 때(5분 이상 지났으면) · 인터넷이 다시 연결될 때 · 켜 둔 동안 15분마다 자동 확인
- 수동: 상단 **⟳ 버튼** 또는 화면을 **아래로 당기기**
- 연결이 안 되면 마지막으로 받은 데이터를 "오프라인" 표시와 함께 보여줌
- 상단 **주차 이름을 누르면** 지난 주차를 볼 수 있음 (최신으로 돌아오는 버튼 있음)

**PC 쪽 (포털 → 모바일)**
| 방법 | 설명 |
|---|---|
| `업데이트.bat` (`py sync.py`) | 지금 한 번 반영 |
| `자동갱신.bat` (`py sync.py --watch`) | 포털에서 계산본을 **게시/재게시하면 1~2분 안에 자동 반영**. 포털을 돌리는 PC에서 켜 두기 |
| `deploy.json` | 호스팅을 정한 뒤 배포 명령을 넣으면 위 동기화 직후 **자동 배포**까지 이어짐 (아래) |

```json
{"command": "vercel deploy dist --prod --yes"}
```
→ 이렇게 해 두면 **포털 게시 → 자동 변환 → 자동 배포 → 폰이 15분 안에(또는 열 때) 최신 반영**.

## 올리는 곳 (아직 올리지 않았음 — 정해 주세요)
설치(홈 화면 추가)는 **HTTPS 주소**에서만 됩니다. `dist/`를 그대로 올리면 되는 정적 호스팅이면 어디든 가능합니다.

| 선택지 | 비고 |
|---|---|
| Vercel / Cloudflare Pages / Netlify | 무료·HTTPS 자동. 가장 간단 |
| 사내 웹서버 | 사내망/VPN 안에서만 열림. 외부 유출 위험이 가장 낮음 |
| ❌ GitHub Pages(공개 저장소) | 쓰지 마세요. 누구에게나 공개됩니다 |

접속 주소 = `https://<호스트>/m-<무작위>/` (빌드 마지막 줄에 경로가 출력됩니다)

## 설치 방법 (직원 안내용)
- **Android(Chrome)**: 링크를 열면 하단에 "설치" 안내 → 설치 (또는 메뉴 ⋮ → 홈 화면에 추가)
- **iPhone(Safari)**: 링크를 Safari로 열기 → 하단 공유 ⎋ → **홈 화면에 추가** (카카오톡 등 앱 안 브라우저에서는 설치 불가 → "Safari로 열기")
- 설치하지 않아도 링크만 눌러 바로 볼 수 있습니다.

## ⚠️ 보안
- 로그인이 없으므로 **링크를 받은 사람은 누구나 볼 수 있습니다.** 주소의 무작위 문자열은 "추측 불가"일 뿐 접근 통제가 아닙니다. 전달받은 사람이 다시 전달하면 막을 방법이 없습니다.
- **대기 인원의 실명(이름+대기 MM)이 `data/*.json`에 들어 있어**, 링크를 받은 사람은 누구나 볼 수 있습니다. 조직별 가동·가득률, 대기 MM, 인사 변동 조직/건수도 사내 정보입니다. 사내 보안 정책상 외부 호스팅이 허용되는지 먼저 확인하세요(포털 README: "외부 인터넷에 공개하지 마세요").
- 주소를 바꾸려면(유출 시) `.token` 파일을 지우고 다시 빌드 → 기존 링크는 모두 무효.
- 폰에 마지막 데이터가 저장됩니다. 분실 시 앱 데이터 삭제 필요.
- 더 안전하게: 사내망/VPN 호스팅, 또는 Cloudflare Access 등 이메일 인증을 앞단에 추가(요청 시 구성 도움).

## 로컬에서 보기
`미리보기.bat` 더블클릭 → 브라우저에 **폰 크기 틀 안에서** 앱이 열립니다 (iPhone/Galaxy/작은 폰/큰 폰 전환).
`py preview.py --lan` = 같은 와이파이의 실제 폰에서도 열기(HTTP라 설치는 안 됨 / 같은 망의 누구나 접속 가능하니 확인 후 끄기).
설치·서비스워커는 localhost 또는 HTTPS에서만 동작합니다.

## 폴더
| 파일 | 역할 |
|---|---|
| `extract.py` | 포털 `meeting.html`에서 모바일용 수치 추출 (대기 인원 이름 포함·인사/휴직 이름 제외, 형식 변경 시 멈춤) |
| `build.py` | 추출 → `dist/` 생성 (앱 껍데기 + data/*.json) |
| `sync.py` | 포털 게시 감지 → 빌드 → (선택) 배포. `--watch`, `--check` |
| `preview.py` | 로컬 미리보기(폰 틀). `--demo` = 가상 데이터 |
| `make_demo.py` | 체험용 가상 데이터 생성(시드 고정, 실데이터 없음) |
| `docs/` | 체험판 빌드 결과 = GitHub Pages 공개 링크용 (`py build.py --demo`로 다시 만듦) |
| `template/assets/` | 앱 아이콘 |
| `template/lite.html·css·js` | 앱 화면 |
| `template/sw.js` | 설치·오프라인. 앱=네트워크 우선, 데이터=네트워크 우선+저장본(오프라인 표시) |
| `.token` | 비밀 주소(공유 금지) |
| `deploy.json` | (선택) 자동 배포 명령 |

## 알려진 한계
- 읽기 전용입니다. 업로드·재계산·게시는 포털(관리자 화면)에서 합니다.
- 포털이 게시하는 `meeting.html`의 표시 형식에 의존합니다. 포털 화면 구조를 크게 바꾸면 `extract.py` 조정이 필요합니다(빌드가 멈추며 알려 줌).
- 자동 갱신은 **이 PC가 켜져 있고 `자동갱신.bat`이 실행 중일 때**, 그리고 배포 대상(호스팅)이 정해진 뒤에 폰까지 이어집니다.
